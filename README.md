# RicePic

RicePic 是一个在线图片压缩与格式转换工具，可以在浏览器中压缩图片、对比效果，并尝试不同编码器。

# 隐私

RicePic 不会把你的图片发送到服务器。图片压缩和处理都在本地浏览器中完成。

RicePic 会使用统计脚本收集基础访问数据，用于了解站点使用情况。

# 开发

开发 RicePic：

1. 克隆仓库
2. 安装依赖：
   ```sh
   pnpm install
   ```
3. 构建应用：
   ```sh
   pnpm run build
   ```
4. 启动开发服务：
   ```sh
   pnpm run dev
   ```
